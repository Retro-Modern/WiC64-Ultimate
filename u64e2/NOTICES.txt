External corresponding SDK sources

The unmodified SDK sources used by both ESP applications are available
without charge from the official Espressif repository:
  https://github.com/espressif/esp-idf
Exact version: v5.3.1
Exact commit: c8fc5f643b7a7b0d3b182d3df610844e3dc9bd74
  https://github.com/espressif/esp-idf/tree/c8fc5f643b7a7b0d3b182d3df610844e3dc9bd74

Retrieve that source revision and all its pinned submodules with:
  git clone --branch v5.3.1 --depth 1 https://github.com/espressif/esp-idf.git esp-idf
  git -C esp-idf checkout --detach c8fc5f643b7a7b0d3b182d3df610844e3dc9bd74
  git -C esp-idf submodule update --init --recursive

The SDK's own original license and copyright notices are included in that
source tree. These SDK sources supply firmware components as well as build
support; they are provided separately from the application sources above.
Prebuilt C64 resources

The following binary inputs are included unchanged from the official
Ultimate firmware repository at commit
60f16dc152177f62901bda7c35692f6be2fc0cb5:
  native/roms/basic.bin: Commodore 64 BASIC ROM 901226-01, 8192 bytes.
  native/software/ModPlayer_16k/module.bin: C64 MOD Player cartridge,
  16384 bytes.
Upstream: https://github.com/GideonZ/1541ultimate/tree/60f16dc152177f62901bda7c35692f6be2fc0cb5

by this package. Their original authors' rights remain applicable. The
